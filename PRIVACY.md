# Privacy Policy — Tree Hierarchy Chart

Last updated: 2026-09-21

Tree Hierarchy Chart is a Power BI custom visual published by
infometricconsultancy ("we", "us").

## Data collection

Tree Hierarchy Chart does **not** collect, transmit, store, or share any
personal data, report data, or usage telemetry, and it makes **no external
network calls** of any kind (no `fetch`, no `XMLHttpRequest`, no analytics
or tracking scripts, no third-party services).

## Data processing

All rendering, filtering, searching, and layout computation happens
entirely client-side, inside the Power BI report canvas (Power BI Desktop
or the Power BI service), using only the fields you place into the
visual's data roles.

## Data persistence

The visual lets you save "views" (expand/collapse state, search text,
zoom, and active measure). This state is written using Power BI's own
`host.persistProperties` API, which stores it inside the report's `.pbix`
file — the same place as any other visual formatting option. Nothing is
sent anywhere outside the report.
